# Daily Verse

A quiet place to reflect. One verse at a time — understand it, apply it, save it.

## Features

- **Today** — a verse to sit with
- **Mood** — pick how you're feeling and get a verse that fits
- **Saved** — keep verses that spoke to you
- **Layered explanations** — Simple, Deeper, For today, and a reflection prompt

Quiet by design. No accounts. Nothing tracked.

## Run

It's a static site — open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

Then visit http://localhost:8000.

## Files

- `index.html` — markup
- `styles.css` — styling
- `app.js` — verse data and view logic
